# Icarus

Learning ML from first principles, in public: from autograd to training and evaluating LLMs.

I'm a software engineer based in Chile with no prior ML background. This repo tracks my path toward research engineering, about 8 hours a week alongside a full-time job. The full roadmap lives in [PLAN.md](PLAN.md).

## Rules

- Every implementation is written from memory, not copied. When I get stuck, I write down what I didn't understand in `NOTES.md`.
- Every month ships something public: code, a write-up, or both.
- I use [Claude Code](https://claude.com/claude-code) as a tutor and reviewer: it explains concepts, reviews my code, and helps with planning and docs. The exercise implementations are mine.
